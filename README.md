# 영업 파이프라인 칸반 보드

빌드 과정 없이 브라우저에서 바로 열리는 단일 HTML 파일 영업 파이프라인 관리 도구입니다. Supabase(Postgres)를 백엔드로 사용합니다.

## 사용 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 서버나 빌드 과정이 필요 없습니다.

## 기능

- 칸반 보드: 리드 → 검토 → 제안 → 협상 → 수주 / 실주
- 카드별 고객사, 딜명, 금액, 담당자, 예상 마감일, 수주 확률 표시
- 카드 추가·수정·삭제, 드래그 앤 드롭으로 단계 이동
- 전체 파이프라인 총액 및 단계별 가중 예상매출(금액 × 확률) 표시
- 모든 변경 사항이 Supabase `stages` / `deals` 테이블에 저장됨

## Supabase 설정

`supabase_schema.sql`을 Supabase 프로젝트의 SQL Editor에서 실행하면 `stages`, `deals` 테이블과 초기 예시 데이터, RLS 정책이 생성됩니다.

`index.html` 하단 스크립트의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 값을 본인 프로젝트 값으로 교체해 사용하세요.

> ⚠️ 현재 RLS 정책은 연습용으로 익명(anon) 사용자에게 전체 읽기/쓰기 권한을 부여합니다. 실제 운영 환경에서는 인증을 추가하고 정책을 제한하세요.
