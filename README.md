# 영업 파이프라인 관리 (엑셀 서식 기반)

빌드 과정 없이 브라우저에서 바로 열리는 단일 HTML 파일 영업 파이프라인 관리 도구입니다. Supabase(Postgres)를 백엔드로 사용하며, 사내 엑셀 파이프라인 관리양식의 시트 구성을 그대로 화면으로 옮겼습니다.

## 사용 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 서버나 빌드 과정이 필요 없습니다.

## 화면 구성 (엑셀 시트 → 메뉴)

- **📖 단계 정의 가이드** — 발굴/접촉/제안/협상/수주/실주/보류 7단계의 정의·진입조건·해야 할 일·주의사항, 단계 관리 4대 원칙 (읽기 전용)
- **📊 대시보드** — 전체딜/진행중딜/진행중파이프라인/수주실적/점검필요딜 KPI, 단계별 현황(진행중), 점검 필요 딜 TOP10, 부서별×단계별 매트릭스
- **📋 딜 파이프라인** — 테이블 보기(엑셀과 동일한 전체 컬럼) / 칸반 보기(드래그 앤 드롭) 전환 가능. 카드·행 추가/수정/삭제
- **📝 활동 이력** — 딜별 미팅·전화·계약협의 등 활동 기록. 딜 선택 시 고객사·부서·담당자 자동 표시
- **🔽 분석** — 단계별 현황(전체), 부서별 성과(수주율 포함), 담당자별×단계별 현황

기준정보(영업부서/담당자/활동유형/알림 기준일수)는 별도 화면 없이 `index.html` 상단 JS 상수로 관리합니다.

## 자동 계산 필드

- **딜상태**: 단계값으로 자동 판정 (진행중/수주/실주/보류)
- **경과일**: 최종 업데이트일 기준 자동 계산
- **D-Day**: 다음 액션일 기준 자동 계산
- **점검알림**: 🔴 액션지연(다음 액션일 경과) → ⚪ 액션일 없음(방치) → 🟠 정체(45일 초과 미업데이트) → 🟡 액션임박(7일 이내) 순으로 자동 판정

## Supabase 설정

프로젝트를 새로 만든다면 아래 순서로 SQL Editor에서 실행하세요.

1. `supabase_schema.sql` — `stages`/`deals` 기본 테이블, RLS, 7단계 기준정보 생성
2. `migration_02_excel_schema.sql` — `deals` 테이블에 엑셀 컬럼 추가, `activities`(활동 이력) 테이블 생성, 엑셀 실데이터 20건 + 활동이력 10건 삽입

`index.html` 하단 스크립트의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 값을 본인 프로젝트 값으로 교체해 사용하세요.

> ⚠️ 현재 RLS 정책은 연습용으로 익명(anon) 사용자에게 전체 읽기/쓰기 권한을 부여합니다. 실제 운영 환경에서는 인증을 추가하고 정책을 제한하세요.
